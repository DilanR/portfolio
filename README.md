## Getting Started

### Prerequisites

- Just Docker!

---

### Installation

```bash
git clone --recursive https://github.com/DilanR/portfolio/
cd portfolio

# Currently rust service builds a statically linked bin so will take some time
docker-compose up --build
```

### Quick Start
See http://localhost:3000/ and run some code!
